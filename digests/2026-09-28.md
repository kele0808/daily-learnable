## 1. [bubbuild/bub](https://github.com/bubbuild/bub)

Bub it. Build it. A tiny agent runtime, composable with plugins.

**为什么看：** 不是再包一层聊天桌面：`process_inbound` 把一回合拆成 resolve_session → load_state → build_prompt → run_model → save_state → dispatch，每段都是 pluggy hook，后装的插件盖过 builtin。上下文不靠可变 session，而是 `Tape` 只追加 message/tool_call/anchor，prompt 每次从磁带重选。`ShellManager` 用 process group 等子进程，取消时先 shield 再清组；这周刚让超时 bash 的输出留下、runtime 退出才收壳，并把 continue_prompt 改成可选。适合看「小运行时」怎么把回合、证据和 shell 生命周期写成可替换钩子。

## 2. [cosmicstack-labs/mercury-agent](https://github.com/cosmicstack-labs/mercury-agent)

Soul-driven AI agent with permission-hardened tools, token budgets, and multi-channel access. Runs 24/7 from CLI, Telegram or More.

**为什么看：** 不是只拦 sudo 黑名单：`splitShellSegments` 把 `echo $(rm -rf ~)`、管道、`&&` 和 `$'...'` 拆成段，blocked / safe-read 按段判，避免 `echo *` 洗白整串。`checkFsAccess` 写路径走 `canonicalizePath`，symlink 跳到可写 scope 外就拒。`isSafeReadSegment` 把 `$TOKEN`、`~user`、ANSI-C quoting 和 `find -exec` 踢出自动放行。这周还把 `github_api` 钉死 https + api.github.com，CLI 的 allow-all 不带去 web channel。适合看工具层权限怎么防「看起来像 cat」的命令。

Agent 框架 · TypeScript · ai-agent · ai-assistant · llm · star 3167

## 3. [nolabs-ai/nono](https://github.com/nolabs-ai/nono)

agent runtime security - zero trust, zero setup, zero latency.

**为什么看：** 不是再套一层容器：`resolve_intercept_action` 按 argv/env 命中 intercept 规则，每条可以自带 `CommandSandboxConfig`，没命中才 passthrough。这周把网络策略按有效命令范围切开——子工具不再继承整段 session 的网，并加了独立 Snap runtime group；代理拒绝写进 CLI 诊断脚。适合对照 mercury 看「应用层拆 shell」和「OS 拦截 + 每命令沙箱」差在哪。

MCP · Rust · agent-sandbox · agent-security · ai-agent-sandbox · star 4244

## 4. [amElnagdy/delegate-skills](https://github.com/amElnagdy/delegate-skills)

Delegate a coding task to a separate coding agent CLI, review the diff, land the commit yourself — one per implementer.

**为什么看：** 不是再堆 SKILL.md：每个 implementer 一份无依赖的 `relay.mjs`，只 spawn 对应 CLI 和 git，自己不联网、不写凭据。`--read-only` 故意做成 `--sandbox --dangerously-skip-permissions`——headless `--print` 没法回答权限提示，不这么配第一次 tool 就会被拒、跑空。落地看 `touchedFiles`（git porcelain），不信 agent 自述；relay 永不 commit。这周给 OpenCode 的 variant dial 加了 CLI 版本探测，并把 agy 权限陷阱写到实测平台/版本。适合看「把任务丢给另一个 coding agent」时沙箱和退出码怎么当合同。
