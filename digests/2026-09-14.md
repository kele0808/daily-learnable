## 1. [Waishnav/devspace](https://github.com/Waishnav/devspace)

Minimal Coding Agent Harness on MCP for ChatGPT, Claude, Hermes, Grok Bot, OpenClaw

**为什么看：** 不是再包一层聊天 MCP：process-sessions.ts 把 exec yield 硬顶在 12s（默认 10s），stdin 交互另走更短窗口，避免 MCP 工具把长命令堵死；LocalAgentManager 只做 turn 生命周期，Claude/Codex/OpenCode/Pi 全在 driver 下面。这周还在砍模型可见指令、钉死 yield 上限。适合看「ChatGPT 当 Codex」时进程和子 Agent 怎么被 MCP 管住。

MCP · TypeScript · agent-orchestration · chatgpt · claude · star 4701

## 2. [truefoundry/trueforge](https://github.com/truefoundry/trueforge)

The open-source agent harness - the runtime layer that turns an LLM into a working agent.

**为什么看：** SessionHandle.createTurn 要求 input 必须同质（全是用户消息，或全是审批/工具回包），开下一 turn 会先 freeze 上一 turn；sandbox.configureCodeMode 只从主线程 toolSets 接一次，再让子线程共用沙箱。AgentThreadOrchestrator + DeferredTool 把延迟装载工具写进循环。这周在收紧命名并补 Python SDK。适合对着 TypeScript 读「会话/回合/线程」怎么拆成可持久化 API。

Agent 框架 · TypeScript · agent · agentic-ai · agents · star 5414

## 3. [Jwuthri/Tracely-ai](https://github.com/Jwuthri/Tracely-ai)

Trace-native CI/CD for AI agents — production failures become regression tests that block the PR. Auto-detect, cluster, freeze into hermetic cases, replay in CI for $0.

**为什么看：** Harbor 是「拿数据集评 Agent」，这里是「线上失败轨迹本身就是测试」。FixtureBundle.capture 按顺序冻住 TOOL/GENERATION span（含 error 和 tool_call_id），contract.py 用 required/forbidden tools + match_mode 做 fail-to-pass；GateService.replay_suite 没 fixture 就报执行错误，绝不空跑。这周还在给 gate 加参数。适合看 $0 回放怎么做成拦 PR 的合同。

评测 / 观测 · Python · agent · agent-observability · ai-agents · star 1411

## 4. [rllm-org/rllm](https://github.com/rllm-org/rllm)

Democratizing Reinforcement Learning for LLMs

**为什么看：** 同一份 @rollout 函数既跑 eval 也进 GRPO。BaseCliHarness 不解析 CLI stdout，只在沙箱里装/配/exec，轨迹靠 gateway 把 LLM 调用打到 /sessions/<uid>/v1。这周刚修层级 task ID 在 GRPO 分组里被拍平。适合对照 Harbor 看「评完还要训练」时 harness 和 reward 怎么共用。
