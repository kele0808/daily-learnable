选出 **4** 个。优先高 star，同时要和 Agent 相关、近期仍在更新。

## 1. [edonadei/caliper](https://github.com/edonadei/caliper)

Run your real agent with and without your skills, MCPs, and rules. See which ones actually help, and what they cost in tokens. Supports Claude Code, Codex, Pi, and Hermes.

**为什么看：** 不是再刷一遍 pass@k：`--ablate` 把「去掉技能」存成一份普通 run，`diff_runs` 才是 compare 的全部逻辑。autorater 两种模式——直接 verdict，或写 `assert` 脚本；脚本超时返回 `None`，不当失败。`classify` 只读 CLI 自己写的字（agent 答「rate limit」不算），这周把 judge 的拒绝按同一套读——quota 中止整场，throttle 才重试。适合看「技能有没有赚回它占的上下文」。

评测 / 观测 · Python · ai-agents · claude-code · cli · star 211

## 2. [N4darae/shrt](https://github.com/N4darae/shrt)

A contract-driven gRPC regression harness for AI coding agents, with human-approved baselines. Snapshot the valid call chains of an API so an agent can look one up instead of tracing for it. gRPC today, OpenAPI next

**为什么看：** 不是再录一遍 HTTP：合同写 `effects`，`plan` 组链，`confirm` 才钉绿。`Without` 抽掉一步会连带抽掉只读它的步。`suspectWrite` 读步坏了先找碰过同一实体的写；写自己的答案变了就还是它自己的嫌疑，除非更早的写够到那个字段。这周 lean-trace 把不清楚的摘要组一次说完，流式步的 verdict 从自己的 messages 读。适合看「编码 agent 改 API 时怎么把红归因到某次写」。

评测 / 观测 · Go · star 1001

## 3. [20000419/fauxnix](https://github.com/20000419/fauxnix)

Run Linux-style commands on Windows via deterministic bash→PowerShell translation. No VM, no WSL. MCP server + CLI built for AI agents (Claude Code, Codex, OpenCode...). GNU-style output, bash-style errors, UTF-8/GBK handled.

**为什么看：** 不是再套一层 WSL：自己 tokenize/parse bash，`translateCommandList` 确定性编成 PowerShell，运行时零 LLM。`pure` 模式连 `sed -f` 都拒读磁盘。这周 facade 冒充 `bash.exe`：剥掉 Claude Code 的 `export && shopt && eval PAYLOAD && pwd -P` 脚手架，只跑 payload，失败不写 cwd marker（对齐 bash 的 `&&`）。适合对照 Windows-MCP 看「UIA 握鼠标」和「内置 Bash 工具改走本地翻译层」差在哪。

MCP · TypeScript · ai-agents · bash · claude-code · star 897

## 4. [aoci-spec/aoci-code](https://github.com/aoci-spec/aoci-code)

A persistent, Git-versioned map of your whole codebase and database schema that coding agents read before they touch anything. Local-first MCP server + CLI in Go: a governed repository index of code knowledge that gives Claude Code, Codex, Cursor, and opencode long-term context, memory, and code intelligence.

**为什么看：** 不是 AST 图谱：模型写一行 FRAS（职责 / 必读 / 接口 / 不能错的），索引进 Git。`#FRAS-v2-Limits-Authority: machine-contract` 字段上限在二进制里，项目改 Meta 加不宽。`validateVolumeAuthoringDelta` 旧的带点 tag 仍能加载，新写必须 compact ABCDE。这周 `fillTargetEScale` 无阈值表不猜档，200 行边界稳定给出 M/S 双档，文件不在盘就留空。适合对照 graphify 看「解析出来的图」和「模型写的、机器守预算的索引」差在哪。

MCP · Go · agent-memory · agents-md · ai-coding · star 1481
