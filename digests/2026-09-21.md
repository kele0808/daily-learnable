# 今日可学 · 2026年9月21日 星期一

选出 **4** 个。优先高 star，同时要和 Agent 相关、近期仍在更新。

## 1. [ApodexAI/FrontierAgent](https://github.com/ApodexAI/FrontierAgent)

🧩 FrontierAgent, our agent framework, open-sourced alongside it — native command-line TUI, ReAct and Agent Team modes, one command on macOS and Linux, no preinstall, no hard Docker dependency.

**为什么看：** 不是再包一层聊天桌面：`render_sandbox_fs_note` 按 sandbox_mode 说实话——container/native 时 `/workspace` 是协调者和所有子 Agent 共享，bwrap 时每个子进程私有，跨 Agent 复用只能走协调者报告。`subagent_runtime` 给 bwrap 单独套沙箱，`/outputs` 默认只读除非点名可写。这周还在修 web tool preflight 和 benchmark 先 shuffle 再截断。适合对照 OMA 看「任务板 + 沙箱拓扑」怎么写成运行时不撒谎。

## 2. [NVlabs/SoL-Pi](https://github.com/NVlabs/SoL-Pi)

SoL-Pi: Scaling Auto-Research Loops for Efficient Agent Harnesses

**为什么看：** NVIDIA 把 auto-research 筛出来的四条效率机制做成 Pi 扩展，不 fork Pi。`executeMutationThenRun` 把 edit/write 和 `then_run` 放进同一文件队列槽，命令前再 sha256 一次，文件变了就标 `THEN_RUN_SKIPPED` 不跑。ObservationPack 不改历史，只在 `pi.on("context")` 投影层：大结果先完整发 `FULL_SENDS` 次，之后换成稳定占位，`obs_recall` 按字节分页；打包失败 fail-open。这周刚链上 arXiv 并把 Pi 钉到 0.85.1。适合看「少花 token 但不藏证据」怎么写成扩展。

Agent 框架 · TypeScript · star 2663

## 3. [the-open-engine/zeroshot](https://github.com/the-open-engine/zeroshot)

Independent executor–verifier orchestration for software changes.

**为什么看：** 写代码的 Agent 不裁决「做完了」。`NativeV2Supervisor.drive` 一次只推一个 admitted run：历史过 `FullV1Reducer`，先把 reducer 授权的 dispatch 记进 SQLite ledger，再 settle 完成。`delivery_unconfirmed`：Required 策略或图里唯一 delivery 节点时，成功必须带匹配 receipt，而且所有 writer 必须在 delivery 开始前停写。这周在加失败 run 从保留 workspace resume，以及把本地 profile 暴露成 ACP。适合看「图才是编排」怎么落成 Rust 监督器。

多智能体 · Rust · agent-loops · agent-orchestration · agentic-workflow · star 1844

## 4. [itayinbarr/little-coder](https://github.com/itayinbarr/little-coder)

A harness optimized to smaller LLMs

**为什么看：** 不是再做一个 Claude Code 克隆：launcher 用 `--no-extensions` 只装绑定的那套，冷启动压在约 7k token。`read-guard-edit` 在 `tool_call` 拦没读过的 edit，`oldText` 必须来自本 session 成功 Read/Write，禁止小模型猜文件。子 coder 默认只读、永不授予 `dispatch`，避免扇出炸弹。这周刚修 edit deadlock，并把 edit/write 和 shell 放进同一确认门。适合对照 SoL-Pi 看「同一套 Pi，一个砍 token、一个教小模型别乱改」。

编程 Agent · TypeScript · ai-coding-assistant · benchmark · code-generation · star 2606
